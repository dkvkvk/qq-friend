## 六、可以直接搬进自己项目的细节

1. **状态要真**：显示真实任务阶段，别做假的「思考中」动画
2. **提醒分场景**：完成 / 出错 / 等待审批，三种声音可分别关
3. **心声气泡**：小概率冒出灰色斜体内心话，比常规对话更像活的
4. **互动三件套**：拖、点、双击，各给一个反馈，不要只有一种
5. **记忆有上限**：40 条左右，超了就丢最早的
6. **一致性靠规格**：体型档位 + 参考图 + 固定描述，缺一不可
7. **表情要带语义**：图 + 台词 + 适用场景，才能「按语境挑」
8. **会闭嘴**：默认不回，被点名或真的相关才开口
